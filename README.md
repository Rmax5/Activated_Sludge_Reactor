# Activated Sludge Reactor Design & Sewage Modelling

## Project Overview

A Microsoft Excel-based design and modelling project for a completely mixed activated sludge reactor treating municipal wastewater. The workbook converts wastewater treatment design equations into a structured, formula-driven engineering model and includes sensitivity analysis for key design parameters.

## Design Basis

| Parameter | Value |
|---|---:|
| Wastewater flow | 10,000 m³/day |
| Influent BOD | 150 mg/L |
| Effluent BOD | 5 mg/L |
| MLSS | 3,000 mg/L |
| Underflow solids concentration | 10,000 mg/L |
| Yield coefficient, Y | 0.5 |
| Decay coefficient, kd | 0.05 day⁻¹ |
| Solids retention time | 10 days |

## Key Design Results

- Reactor volume: **1,611 m³**
- Wasted solids generation: **483.3 kg/day**
- Waste sludge flow: **48.3 m³/day**
- Return sludge flow: **4,216.7 m³/day**
- Recycle ratio: **42.2%**

## Excel Model

The workbook contains:

- **Inputs** — design parameters and assumptions
- **Calculations** — BOD loading/removal, reactor volume, solids generation and sludge flows
- **Design Summary** — key calculated design outputs
- **Sensitivity Analysis** — effect of MLSS, flow and underflow concentration on design parameters

The model is formula-driven so that changing the design inputs automatically updates the corresponding calculations and outputs.

## Engineering Concepts Demonstrated

- Activated sludge process design
- BOD loading and removal
- Biomass/solids balance
- Reactor sizing
- Sludge wasting
- Return activated sludge calculation
- Recycle ratio
- Sensitivity analysis
- Engineering spreadsheet modelling
